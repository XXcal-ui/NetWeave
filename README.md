   # NetWeave

   Sistem monitoring keamanan dan deteksi anomali jaringan berbasis IoT.
   Sensor ESP32 memantau lalu lintas jaringan LAN, mendeteksi serangan
   (port scanning, SYN flood, ICMP flood, ARP spoofing, brute force),
   dan mengirim peringatan lewat dashboard dan Telegram.
